# La Crypta — Rovereto

Sito one-page per La Crypta, cocktail bar in Via Portici 16, Rovereto. HTML, CSS e JavaScript senza dipendenze: si pubblica così com'è (GitHub Pages, Netlify, qualsiasi hosting statico).

- `index.html`: la pagina
- `styles.css`: token di colore e tipografia, layout, animazioni
- `main.js`: stato "aperto adesso" (ora di Roma, 18–02), selettore delle firme, entrate allo scroll
- `assets/img/`: foto (Unsplash, licenza Unsplash)

## Da confermare prima del lancio

- Nomi, ricette e prezzi dei drink sono di esempio.
- Telefono: il sito usa 0464 480555 (pagina Facebook); online compare anche 0464 669577.
